One-line: the Daily Process contribution bar — proportional colour blocks with fine tick hatching.

```jsx
<StackedBar segments={[
  {value:28,color:"var(--data-calories)"},
  {value:24,color:"var(--data-nutrition)"},
  {value:22,color:"var(--data-exercises)"},
  {value:26,color:"var(--data-steps)"}
]} />
```

- Always pair with a `Legend` below and a 0 / 100% axis pair.
