One-line: the standard form field — label above, dark fill, red asterisk when required.

```jsx
<Input label="Full name" required placeholder="e.g, Ahmad Bergson" />
<Input label="Height" required placeholder="0.00" unit="cm" />
<Input label="Date of Birth" required placeholder="Select date" icon="calendar" />
```

- Placeholders are written as examples ("e.g, Ahmad Bergson"), not instructions.
- Focus is a 1px Blue Glow border; there is no glow ring on inputs.
