One-line: any headline number in the product (durations, scores, timers, streaks) set in the Doto dot-matrix face.

```jsx
<DotNumber value="32" unit="min" />
<DotNumber value="93.2" size="hero" unit="%" />
```

- Only numbers use Doto. Never set sentences or labels in it.
- Pair with an Inter label beneath at `--fs-micro` uppercase.
