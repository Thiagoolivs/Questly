One-line: monochrome UI glyph, masked from the Lucide static set so it inherits `color`.

```jsx
<Icon name="bell" size={20} color="var(--text-primary)" />
```

- LGrow uses thin, rounded line icons at 16/20/24px, always single-colour (white, silver, or Blue Glow).
- Never fill icons; never use emoji as an icon (emoji appear only inside written copy).
